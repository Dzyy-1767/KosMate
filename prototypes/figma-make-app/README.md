# KosMate Web Prototype

This is the standalone Vite/React prototype. It is separate from the Expo
mobile application in `frontend/`; changes here do not affect the mobile app.

## Run locally

From the repository root:

```bash
cd prototypes/figma-make-app
npm ci
npm run dev
```

Create a production build with `npm run build`. This project uses
`package-lock.json` and npm.
